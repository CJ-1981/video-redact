Serve this app over localhost

This page was opened from file://. Browsers block the secure APIs the app needs (WebCodecs, IndexedDB, WASM) there, so redaction is disabled. Run one of these from the app folder and open the printed localhost URL instead:

python3 -m http.server 8000 npx serve
